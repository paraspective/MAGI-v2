# MAGI Archive

This directory stores historical CAD prototypes, earlier URDF iterations, legacy monolithic test scripts, and third-party reference designs. None of the files in this directory are part of the active production build.

---

## Directory Organization

```
archive/
├── cad_prototypes/       Early servo plate and chassis brackets (tested for flex and clearance)
├── urdf_iterations/      Historical URDF exports (URDF_initial, URDF_v1, MAGI_iteration3)
├── legacy_scripts/       Monolithic Python prototypes used before migrating to MAGI OS
└── references/           Attributed open-source reference models and benchmarks
```

For notes on the reference quadrupeds and citations, see [`references/REFERENCES.md`](references/REFERENCES.md).
